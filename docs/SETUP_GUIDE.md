## ۱. نصب گام‌به‌گام (ویندوز / PowerShell)

فایل ZIP را از حالت فشرده در بیاورید، PowerShell را در پوشهٔ پروژه باز کنید و به
ترتیب اجرا کنید. **بعد از هر دستور صبر کنید تمام شود.**

### گام ۱ — محیط مجازی بسازید

```powershell
python -m venv .venv
```

محیط مجازی یعنی کتابخانه‌های این پروژه جدا از پایتون سیستم نصب می‌شوند تا با
پروژه‌های دیگر تداخل نکنند.

### گام ۲ — محیط را فعال کنید

```powershell
.venv\Scripts\Activate.ps1
```

**اگر خطای اجرای اسکریپت داد** (`cannot be loaded because running scripts is disabled`)،
یک بار این را اجرا کنید و بعد دوباره فعال‌سازی را امتحان کنید:

```powershell
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
```

نشانهٔ موفقیت: اول خط فرمان `(.venv)` ظاهر می‌شود.

### گام ۳ — pip را به‌روز کنید

```powershell
python -m pip install --upgrade pip
```

### گام ۴ — نصب dlib (فقط ویندوز، قبل از بقیه)

این گام را **قبل** از `requirements.txt` انجام دهید:

```powershell
pip install https://github.com/z-mahmud22/Dlib_Windows_Python3.x/raw/main/dlib-19.24.1-cp311-cp311-win_amd64.whl
```

**چرا این گام جدا است؟** `dlib` کد ++C است و نصب معمولی‌اش روی ویندوز به Visual
Studio Build Tools نیاز دارد (چند گیگابایت دانلود). این لینک یک نسخهٔ **پیش‌کامپایل‌شده**
است که این دردسر را حذف می‌کند.

> فایل ویل بالا برای **پایتون ۳.۱۱** است (`cp311`). اگر پایتون ۳.۱۰ دارید، در آدرس
> `cp311` را به `cp310` عوض کنید.

**در لینوکس/مک** این گام لازم نیست، فقط اول:
```bash
sudo apt install cmake build-essential   # اوبونتو
```

### گام ۵ — نصب بقیهٔ وابستگی‌ها

```powershell
pip install -r requirements.txt
```

این گام **طول می‌کشد** (چند دقیقه). حجم دانلود حدود ۵۰۰ مگابایت است چون `onnxruntime`،
`opencv` و `scipy` سنگین‌اند.

### گام ۶ — فایل تنظیمات بسازید

```powershell
Copy-Item .env.example .env
```

فایل `.env` تنظیمات محلی شماست. حالا **دو مقدار را در آن عوض کنید** (با Notepad یا
VS Code بازش کنید):

```ini
# اگر وب‌کم شما کار نکرد، این عدد را ۱ یا ۲ کنید
CAMERA_INDEX=0

# روی 0.5 بگذارید؛ 0.25 برای تشخیص خیلی کوچک است
PROCESS_SCALE=0.5
```

### گام ۷ — تست بگیرید (بررسی سلامت نصب)

```powershell
python -m pytest tests -q
```

**نتیجهٔ درست: `125 passed`** (حدود ۴۵ ثانیه طول می‌کشد).

اگر این عدد آمد، نصب شما **کامل و درست** است. اگر تعدادی fail شد، به بخش ۵ (عیب‌یابی)
بروید و **قبل از اجرای سرور** حلش کنید.

### گام ۸ — سرور را اجرا کنید

```powershell
python -m uvicorn main_fastapi:app --host 127.0.0.1 --port 5000
```

**بار اول این دستور، ~۳۲۵ مگابایت مدل دانلود می‌شود** (`buffalo_l`). این یک بار اتفاق
می‌افتد و مدل‌ها در `C:\Users\<نام شما>\.insightface\models\` ذخیره می‌شوند. صبور باشید
و اینترنت را قطع نکنید.

### ✅ نشانهٔ موفقیت

در لاگ استارتاپ باید **این خط** را ببینید:

```
[FaceRecognizer] InsightFace ready (buffalo_l, ArcFace 512-d, det_size=320)
Recognition engine: insightface_arcface
```

> 🔴 **اگر نوشت `dlib` یا `fallback`، موتور اصلی کار نمی‌کند.** این همان باگ ۱۱ پروژه
> است. بخش ۵ را ببینید. **این را جدی بگیرید** — سیستم کار می‌کند ولی با موتور ضعیف‌تر
> ۱۲۸ بُعدی، و در ارائه نمی‌توانید بگویید از ArcFace استفاده می‌کنید.

## ۳. اولین کاری که باید بکنید: خودتان را ثبت‌نام کنید

> **این مهم‌ترین کار شماست.** الان دیتابیس فقط یک کارگر دارد. برای دمو باید **هر سه
> نفر** ثبت‌نام شوید، وگرنه نمی‌توانیم اثبات کنیم سیستم هویت‌ها را از هم **تفکیک**
> می‌کند — و این ضربه‌پذیرترین نقطهٔ دفاع ما است.

1. `http://127.0.0.1:5000/admin` را باز کنید → رمز `admin` / `admin`
2. بخش **ثبت‌نام** → نام و شناسه بدهید (`W002`، `W003`)
3. **۶ ژست** را کامل کنید: روبه‌رو، چپ، راست، بالا، پایین، لبخند
   - در نور **کافی** بنشینید
   - فاصله حدود **۵۰ سانتی‌متر** از دوربین
   - ژست‌ها را جدی بگیرید — همین تنوع است که سیستم را در شرایط واقعی مقاوم می‌کند
4. بعد از ثبت، در پنل روی ردیف خودتان کلیک کنید: باید **عکس‌های بندانگشتی** نمونه‌ها
   و **ابعاد ۵۱۲** را ببینید
5. **تست تفکیک:** جلوی دوربین بروید؛ باید **نام خودتان** بیاید نه نام نفر دیگر

اگر «مهمان» نشان داد یعنی شباهت زیر آستانه بوده — نور را بهتر کنید و یک نمونهٔ دیگر
از پنل اضافه کنید (دکمهٔ `+ دوربین`).

## ۵. عیب‌یابی — خطاهای واقعی و رفعشان

### ❌ `ModuleNotFoundError: No module named 'X'`

محیط مجازی فعال نیست. اول خط فرمان `(.venv)` را چک کنید. اگر نبود:
```powershell
.venv\Scripts\Activate.ps1
```

### ❌ نصب `dlib` شکست می‌خورد / خطای CMake

گام ۴ را جا انداخته‌اید یا نسخهٔ پایتون نمی‌خورد. `python --version` را چک کنید و
در آدرس ویل `cp311` را با نسخهٔ خودتان مطابق کنید (`cp310` برای ۳.۱۰).
**اگر پایتون ۳.۱۲+ دارید، باید ۳.۱۱ نصب کنید — راه دیگری نیست.**

### ❌ لاگ می‌گوید `dlib` نه `insightface_arcface`

سه علت ممکن، به ترتیب احتمال:

1. **مدل دانلود نشده** — پوشهٔ `C:\Users\<شما>\.insightface\models\buffalo_l\` را چک
   کنید؛ باید `det_10g.onnx` (۱۶ MB) و `w600k_r50.onnx` (۱۶۶ MB) داشته باشد. اگر
   نبود، اینترنت را وصل کنید و سرور را دوباره اجرا کنید.
2. **`.env` غلط** — `PREFER_INSIGHTFACE=true` باشد
3. **`INSIGHTFACE_DET_SIZE` غیرمربع** — این همان باگ ۱۱ ماست. مقدار باید یک **عدد**
   باشد (`320`)، چون کد از آن یک مربع `(320, 320)` می‌سازد. مدل SCRFD با ورودی
   غیرمربع خطای broadcast می‌دهد.

### ❌ دوربین باز نمی‌شود / تصویر سیاه

- برنامهٔ دیگری (Zoom، Teams، Skype، مرورگر) دوربین را گرفته → ببندید
- `CAMERA_INDEX` را در `.env` روی `1` و بعد `2` امتحان کنید
- ویندوز: تنظیمات → Privacy → Camera → دسترسی برنامه‌های دسکتاپ را روشن کنید

### ❌ خطای `Address already in use` / پورت اشغال

سرور قبلی هنوز در حال اجراست. آن پنجرهٔ PowerShell را با `Ctrl+C` ببندید، یا:
```powershell
python -m uvicorn main_fastapi:app --port 5001
```

### ❌ کسی را نمی‌شناسد و همه را «مهمان» می‌گوید

به ترتیب چک کنید:
1. **نور** — کم‌نوری باعث رد شدن در دروازهٔ کیفیت می‌شود (این عمدی است)
2. `PROCESS_SCALE=0.5` باشد نه `0.25`
3. آیا **در پنل ادمین** برای خودتان نمونه ثبت شده؟
4. اگر همه درست بود، از پنل چند نمونهٔ دیگر با `+ دوربین` اضافه کنید

### ❌ تست‌ها fail می‌شوند

اول خروجی کامل را ببینید:
```powershell
python -m pytest tests -v
```
اگر مربوط به `insightface` بود، مدل دانلود نشده. اگر مربوط به دیتابیس بود، `.env`
را چک کنید. اگر تعداد `passed` کمتر از ۱۲۵ ولی `failed` صفر است، احتمالاً چند تست
`skip` شده‌اند که مشکلی نیست.

### ❌ داشبورد باز می‌شود ولی تصویر نمی‌آید

`CAMERA_ENABLED=true` در `.env` باشد. اگر بود، در داشبورد دکمهٔ روشن کردن دوربین
را بزنید (دوربین به‌صورت **تنبل/lazy** فقط وقتی لازم شود شروع می‌شود).

## ۷. ⚠️ نکات مهم

- **رمز ادمین `admin` / `admin` است.** برای کار محلی مشکلی نیست، ولی اگر سرور را روی
  شبکه گذاشتید **باید** در `.env` عوض شود. در ارائه هم خودمان این را به‌عنوان

  اجرا کند.

- **مدل‌های ۳۲۵ مگابایتی در ZIP نیستند.** بار اول اجرای سرور خودکار دانلود می‌شوند.

- **همه چیز آفلاین است.** هیچ تصویری به اینترنت نمی‌رود؛ اینترنت فقط برای نصب لازم است.
